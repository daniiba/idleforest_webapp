# Eco Search Acquisition Cluster Plan

Date: 2026-05-09

## Goal

Grow acquisition from people already researching Ecosia, OceanHero, Tab for a Cause, Ekoru, TreeClicks, and eco-search behavior. IdleForest should be positioned as a complementary passive tree-funding layer that works alongside existing search engines, not as a direct search-engine replacement.

## Primary Pillar

Keep `/eco-friendly-search-engine` as the pillar page for:

- eco friendly search engine
- green search engine
- search engine that plants trees
- tree planting search engine
- Ecosia alternative

The page should answer the broad intent directly, then route users into specific trust, review, and comparison pages.

## Keyword Ownership Map

- `/eco-friendly-search-engine` owns broad discovery intent: `eco friendly search engine`, `green search engine`, `search engine that plants trees`, `tree planting search engine`, and broad `Ecosia alternative` comparisons.
- `/use-idleforest-with-ecosia` owns companion intent: `use IdleForest with Ecosia`, `IdleForest Ecosia`, `Ecosia complement`, and `plant more trees with Ecosia`.
- `/compare/idleforest-vs-ecosia-vs-treeclicks` owns direct comparison intent: `IdleForest vs Ecosia`, `IdleForest vs TreeClicks`, `Ecosia vs TreeClicks`, passive vs search-based vs shopping-based tree funding.
- `/ecosia` owns proof and data intent: `Ecosia financial data`, `Ecosia tree planting data`, `Ecosia financial report`, and historical tree metrics.
- `/is-ecosia-legit-safe` owns trust intent: `is ecosia legit`, `is ecosia safe`, `ecosia privacy`, and `ecosia tree planting proof`.
- Existing Hashnode Ecosia-alternative roundup should be treated as a spoke or supporting list post, not the canonical broad hub. Add contextual links from that article to `/eco-friendly-search-engine` with anchors like `eco-friendly search engines` and `search engines like Ecosia`.

Status note, 2026-05-09: the Hashnode Ecosia alternatives roundup was updated as a spoke. It now links to `/eco-friendly-search-engine` and `/use-idleforest-with-ecosia`, and its IdleForest description now reflects the browser extension plus desktop app and opt-in idle bandwidth model.

## Hub Structure

The pillar should include:

1. Direct answer above the fold: Ecosia is the best-known tree-planting search engine; IdleForest adds passive verified tree funding without changing search engines.
2. Quick-picks comparison table with `Tool`, `Type`, `Best for`, `Search switch required?`, `Impact model`, `Proof/transparency`, and `Use with IdleForest?`.
3. A section for `What search engine plants trees?`.
4. A section for `Best eco-friendly search engines and browser tools`.
5. A section for `Ecosia alternatives if you do not want to change search engines`.
6. Trust section covering legitimacy, privacy, search provider dependencies, financial reports, certificates, and impact proof.
7. Internal link cards to the strongest existing pages.

Schema:

- `CollectionPage` or `WebPage`
- `BreadcrumbList`
- `ItemList` for compared tools
- visible `FAQPage`

Do not over-rely on FAQ rich results; Google limits FAQ display mostly to highly authoritative health/government sites.
